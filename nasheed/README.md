# الأناشيد

حط هنا ملفات الأناشيد (mp3) اللي عايزها تشتغل في خلفية التطبيق، وسمّي كل ملف باسم النشيد.

- اختار أناشيد **من غير موسيقى**، ومسموح لك تستخدمها.
- بعد الرفع، GitHub هيبني نسخة جديدة فيها الأناشيد على الموبايل واللاب.
- تقدر كمان تضيف أناشيد من جوه التطبيق نفسه: صفحة **الأناشيد ← اختار ملفات**.
