# أصوات الأذان

حط هنا ملفات الأذان (mp3 أو ogg أو wav)، وسمّي كل ملف باسم المؤذن، مثلاً:

- `أذان الحرم المكي.mp3`
- `الشيخ فلان.mp3`

بعد ما ترفعها، GitHub هيبني التطبيق من جديد، وهتلاقي الأصوات في صفحة "التنبيهات" تختار منها.

استخدم بس تسجيلات مسموح لك باستخدامها. خلي كل ملف أقل من 5 ميجا علشان حجم التطبيق.
